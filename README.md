# Final-Project
NewsHub is a web-based News Aggregator App that brings the latest news from different categories like Technology, Sports, Education, and Entertainment into one platform. It features user registration, login, news search, category filtering, and an admin dashboard to manage news articles, built using HTML, CSS, JavaScript, Node.js, and Express.
